# Publication provenance

This public repository is a reviewed source snapshot of the locally maintained RTX-Monitor application. It was prepared as private and changed to public only after the owner explicitly requested that visibility. Existing local repositories and their histories were left unchanged.

The original application folder did not have an independent Git history.

Deployment-specific user paths, LAN identifiers, and device MAC addresses have been replaced with illustrative values. Configure real values locally. No live credentials, sessions, databases, personal records, raw downloads, game ROMs, firmware images, dependency folders, or build outputs are included. Generated source templates required by the application and their retained license notices remain included.

The original deployment is unchanged. Installation commands are intended for a separate checkout and require local configuration before use. See README.md and CHECKS.md.
